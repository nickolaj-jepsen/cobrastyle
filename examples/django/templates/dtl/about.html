How it works

This page is Django Template Language; the home page is Jinja2. Both engines share the same CSS modules, and one build covers them both.

In development every stylesheet compiles on demand. In production manage.py cobrastyle_build writes hashed CSS plus a manifest, and the app never imports the compiler.
